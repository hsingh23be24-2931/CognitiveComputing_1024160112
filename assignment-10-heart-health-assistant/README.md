# Assignment 10 — Heart Health Information Assistant (Even Roll)

UCS420 Cognitive Computing · Roll number: 1024160112

Includes 64 labeled queries across eight intents, a four-category taxonomy, a 12-relationship ontology, a curated knowledge base, TF-IDF + Logistic Regression, train/test evaluation, a rules engine, and a CLI assistant. Run `python main.py --demo` for the required test query categories. Run `python colab_notebook_generator.py` to regenerate the notebook. In Google Colab upload `main.py`, `intents.csv`, `knowledge_base.json`, `ontology.json` and `taxonomy.json` in the notebook upload cell; then run the following cells. This educational tool cannot diagnose or provide emergency treatment.

## Run

```bash
pip install -r requirements.txt
python main.py --demo
python main.py
```
